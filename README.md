# 砖造工坊 · 颗粒积木定制系统

浏览器内的宠物/模型 → 颗粒积木转换与搭建图纸系统。TypeScript + Vue 3 + WebGPU + Three.js。

## 功能与页面

| 页面 | 能力 |
| --- | --- |
| 订单列表 | 订单增删改、工程 JSON 导入导出、localStorage 持久化 |
| 模型导入 | OBJ（含 MTL/贴图）、glTF/GLB 解析与贴图烘焙；无模型时程序化生成坐猫、小房子 |
| 体素化 | WebGPU 计算着色器栅格化（不支持时自动降级 CPU，同算法同结果）、分辨率/壳厚/颗粒尺寸可调、分层预览 |
| 配色 | 贴图色量化到颗粒色卡（Lab 最近邻）、逐颗锁定、缺货自动换最近色、用量统计 |
| 搭建图纸 | 合砖、稳定性分析、自动支撑、分步搭建（新砖高亮）、零件清单、PDF/CSV/PNG 导出 |
| 设置 | 砖型供给、自动支撑/缺货替换开关、性能基准、本地存储管理 |

## 核心算法

### 体素化
- GPU 与 CPU 共用同一套 SAT 三角-AABB 重叠测试（`core/voxel/triangle_box.ts` 与 `voxelize.wgsl.ts`），保证两条路径产物一致。
- 洪水填充区分内外，封闭空腔填实；多源 BFS 距离场做等厚掏空，薄颈处距离恒小于壳厚因此不会被切断。
- **加强筋掏空**：等厚壳之外，每隔 `RIB_SPACING`（默认 8 格）保留一层实体网格墙，把大内腔切成砖可跨越的小腔。这是同时满足「省料」与「可搭建」的关键。

### 合砖与结构（`core/brick_merger.ts`）
- 同色 4 邻接连通域内贪心铺砖，大砖优先；候选打分偏好跨越下层接缝，实现层间交错咬合、避免整列对齐。
- 自动支撑自底向上：实心格下方非实心（空或掏空）即在该列补 1×1 柱到最近实体，逐格幂等。
- **零悬空可证明**：支撑处理后每个非底层实心格正下方都是实心，故铺出的每块砖都与下层实体咬合。冒烟测试以「砖足迹至少一格咬住下层 owner」复核，实测悬空 = 0。
- 稳定性扫描零支撑、大砖低支撑覆盖率、跨层孤岛；1×1 单点连接属正常乐高结构，不误报。

### 关于省料与结构的权衡（重要）
纯等厚掏空会制造贯穿模型的巨大空腔，若要求每个悬空格都有落地柱，柱子会填满空腔、省料收益归零。本系统用加强筋把空腔限制在砖跨距内，实测相对全实心**省料约 38%–44%**，同时保证零悬空、可手工搭建。若需进一步省料，可增大 `RIB_SPACING` 或在设置页关闭自动支撑改由人工设计，但需自行承担悬挑风险。

## 性能
冒烟测试（`pnpm test:smoke`，CPU 路径）：约 19 万实心体素的全链路（体素化+配色+合砖）约 1.5s，合砖本身 <1s，满足「十万体素 ≤10s」红线。WebGPU 路径在支持的浏览器上更快。

## 常用命令
```bash
pnpm install
pnpm dev          # 本地开发
pnpm build        # 类型检查 + 生产构建
pnpm test:smoke   # 核心算法冒烟测试（结构红线、省料、性能）
```
